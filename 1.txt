- Створіть новий локальний репозиторій
- проініціалізуйте його гітом
- створіть у ньому html, підключіть css і додайте 3 файли з типом(розширенням) ".rt2" (не ".rt2.txt" а саме ".rt2")
- Видайте на всю сторінку будь-який градієнт і по центру будь-яке слово
- зробіть так, щоб гіт ігнорував усі файли типу ".rt2", у яких ім'я закінчується на символ "f" (не перераховуючи кожен файл окремо)
- Створіть новий віддалений репозиторій на github
- завантажте файли з локального проекту до репозиторію на github(всі)
- хостите його на gitHub-pages
- у дз вказуєте коментарем до дз(без завантаження файлів) посилання на репозиторій (не на pages!!)


- розберіть самостійно, що таке README файл для github репозиторіїв
- додайте README до свого репозиторію з вашим прізвищем і будь-якою картинкою
